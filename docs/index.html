Overview & design north star

Block Buddies is a 2D cartoon platformer built for Jack, a five-year-old. It is a single HTML page plus six plain JavaScript files — no build step, no dependencies, no asset files. All art is procedural canvas drawing and all audio is procedural WebAudio. It runs from file://, from GitHub Pages, and as an installable PWA (fullscreen "Add to Home Screen" play, including iPhone).

The success metric that governs every decision: "Does Jack immediately understand it, and does he want to play again?" Forgiveness beats challenge. Icons instead of text. Everything is cartoon-cute: big googly faces on everything — blocks, terrain, the sun, trees, the volcano, a planet. No gore, ever: enemies "poof" into stars and candy, or better, become friends.

  • Live URL: polarispixels.github.io/block-buddies (GitHub Pages, main branch, repo root; deploy = push, rebuild ~40–60 s)
  • Canvas: 1280 × 720 logical pixels (W/H in js/util.js), scaled to fit the screen
  • Controls: Arrow keys move/jump/duck (or swim/fly), Space = action (throw power, advance dialogs, open things). Touch: left-thumb ◀▶▼ cluster, right-thumb JUMP + ★ action (becomes ▲▼ underwater/space). Digits 1–9 (and 0 for world 10) jump to a level from the title.

Versioning (SEMVER)

The game is versioned with Semantic Versioning starting at 1.0.0 (the first versioned release: nine complete worlds, two bosses, three vehicles, PWA support).

BumpWhenExamples
MAJORBreaking changes to saved progress (localStorage keys/format) or a rework that invalidates this document's architectureChanging the meaning of ffbg_unlocked; replacing the level format
MINORNew player-visible content or featuresA new level, a new vehicle, a new enemy, a new power
PATCHBug fixes, tuning, visual/audio polish with no new contentFixing a projectile height, adjusting a hitbox

The version lives in one place in code: GAME_VERSION at the top of js/util.js. It is rendered as a tiny stamp in the bottom-left corner of the title screen — which doubles as a quick way to confirm a live deploy took effect. Every release must:

  1. Bump GAME_VERSION in js/util.js
  2. Add a matching ## [x.y.z] entry to CHANGELOG.md (Keep-a-Changelog style)
  3. Update the version badge in this document (docs/index.html)
  4. Tag the release commit: git tag vX.Y.Z && git push --tags

The test harness enforces #1–#3: it fails if GAME_VERSION isn't valid SEMVER, if the changelog lacks an entry for it, or if this page doesn't mention it.

Hard rules

  1. Zero build step. Plain <script> tags, no ES modules, no npm, no bundler. index.html must keep working from file://.
  2. No asset files. All art is procedural canvas drawing; all audio is procedural WebAudio. Everything gets a face; nothing gets gore.
  3. Design for a five-year-old. Icons instead of text, generous hitboxes, frequent checkpoints (they refill hearts), no fall deaths, auto step-up on ≤52 px ledges, unlimited retries, bosses show icon hints when you use the wrong power.
  4. Verify before claiming done. Run node test/harness.js (must print ALL CHECKS PASSED) and screenshot new visuals with tools/screenshot.sh.

Architecture

Six scripts loaded by index.html in a fixed order; they share globals (no modules), so load order matters:

Conventions

  • Entities: x, y is the top-left corner of a w × h box; cx/cy getters give the center. World units are pixels.
  • Ground: the walkable ground top is y = 620 in most levels (1000 in Unicorn Forest; Space Maze is a 130 px cell grid).
  • Levels are plain objects from buildLevel(n): arrays of solids, spiders, pickups, checks (checkpoints), hints, plus theme flags (water, dark, fallCatch, space, boss…) and optional structures (lava, ramps, turbos, bridges, centipedes, mazeGrid, goalStar, castleX, finishX).
  • PWA: manifest.webmanifest + sw.js (network-first cache named ffbg-v1) — one refresh picks up a new deploy; the game keeps working offline afterwards.

Core systems

The player

3 hearts, refilled at every checkpoint. Taking a hit removes one heart and grants a generous invulnerability window; at zero hearts the player respawns at the last checkpoint (unlimited retries, vehicle preserved). Movement: run 300 px/s, jump; in water/space it becomes free 4-direction swimming. Ledges ≤52 px are stepped up automatically.

Power blocks (carried one at a time, thrown with Space/★)

BlockProjectile effectFirst appears
🔥 FireFast fireball; pops angry enemies into stars/candy. In Lava World it instead ignites spiders, who panic-run and then explode — clusters chain-react.Level 1
❄️ IceFreezes an enemy into a harmless ice block (frozen swim-spiders float upward). Required for boss stages.Level 2
🌈 RainbowSlow wavy shot that befriends an enemy — hearts, a smile, and it follows you around. Befriends whole centipedes and aliens. Every boss is ultimately befriended, never killed.Level 3
⭐ PowerNot a projectile: 6 seconds of super mode — rainbow-flashing, faster (440 px/s), higher jumps, shielded from damage, and smashes breakable walls / rams bosses.Level 4

Forgiveness features (never remove these)

  • No fall deaths: Cloud World catches falling players with a friendly cloud and returns them to safety; lava pools bounce the player out at the cost of one heart.
  • Checkpoints refill all hearts; death during a boss respawns inside the sealed arena (at arenaL + 20), never outside it.
  • Icon hints: floating keycap/icon hints teach controls; bosses pop an icon bubble showing the needed power when hit with the wrong one.

Vehicles

player.vehicle ∈ wheel (the default block wheel) / truck / unicorn. Boarding happens by walking or driving into a ParkedTruck / ParkedUnicorn placed in lv.pickups; boarding resizes the hitbox, and respawns keep the vehicle. Each level resets to the wheel.

Bosses

All three bosses share one slot — game.zombie holds a Zombie, Magma, or Spino (same interface: update/draw/hitBy/setState/hp/groundY). The boss trigger x is per-level via lv.bossX (default 3900). The Spinosaurus seals its arena on both sides (game.spinoWalls, broken on friendship) since the level continues past it. game.bossPlan maps each stage to its required power; wrong hits show a hint bubble and do no harm. Boss power-block pickups respawn via bossKind. The arena seals behind a rock wall during the fight.

Adventure missions: distributed collection (since v1.5.0)

Both missions follow one pattern: discover the locked gate → find the Shrine showing three empty sockets → explore and collect three scattered tokens (any order, each a different simple challenge) → return to the Shrine → ceremony opens the chest → mission key appears → carry it to the gate. Classes live at the end of js/entities.js; a level opts in by setting lv.mission in buildLevel. The mission state machine is one field:

Mission.state:  'puzzle' → 'reward' → 'carrying' → 'done'
                 collect     key waits   key follows   gate opened
                 all tokens  at shrine   the player    for good
  • MissionGate — blocks the path with its own solid (removed on unlock via the same solid.broken = true trick smashed walls use). Bumping it while locked: CLUNK/stone-grind, a shake, a worried face, and a thought-bubble showing the key it wants. It only checks mission.state === 'carrying' — it never asks how the item was earned.
  • CollectionPuzzle — the objective: an array of MissionTokens plus a Shrine. Tokens collect in any order; there are no wrong inputs, no resets, no sequences to memorize. When count() equals the token total and the player comes near the shrine, a short ceremony runs: tokens fly into sockets one at a time (ding per socket), the shrine shakes, the chest opens, and mission.item.revealAt(...) is called. Collected tokens persist through deaths and checkpoint respawns (mission state lives on the level object; it resets only when the level restarts).
  • MissionToken — one collectible piece. kind is a POW color key; skin picks artwork ('crystal' gems for Mountain, 'egg' for the Jungle). MissionToken.drawIcon renders the same icon at any size for tokens, shrine sockets, and the progress toast. After every pickup a wordless toast pops over the hero — three icons, collected ones bright with a star, missing ones dim. The final pickup gets a stronger fanfare.
  • Shrine — the landmark: a glowing treasure chest that has been there all along, plus three sockets showing ghost silhouettes of the missing tokens (collected-but-not-yet-placed ones pulse). Themes: 'stone' (Mountain crystal pedestal) and 'nest' (Jungle nest bowls, vines draped over the chest until it opens, and a one-second gag where a placed egg cracks and a little eye peeks out).

Design intent per token — difficulty comes from reaching things, never from logic: token 1 is a visible easy grab ("I see it, I can get it"), token 2 is visible but too high — a nearby bouncer launches the player up ("how do I get up there?"), token 3 is gated behind a mechanic the player already learned ("I know what to do") — Mountain: a cracked wall power-smashed open (the pocket is sealed solid on its far side so it can't be sneaked into); Jungle: an egg bobbing in the shrine guard's flame path, taken by timing the fire cycle (or freezing/ befriending the guard — all fair).

Bouncers (reusable launch pads)

Any solid with bouncy: true is a bouncer; bounceVy sets launch strength (default −980 ≈ 2× jump height; the mission ledges use −1150 ≈ 3×). Add one with addPlat(lv, x, y, w, {bouncy: true, h: 40, bounceVy: -1150}). Skins follow the level theme automatically: pink spring block everywhere, pink booster mushroom in forest/jungle. Overshoot generously and give wide landing platforms (oneWay: true so the player sails up through them) — bouncing should never need precision.

Fire-breather hazard (since v1.4.0)

FireBreather (js/entities.js, kind = 'firedino') is a reusable timed jump-over hazard. It lives in lv.spiders, so every existing enemy hook (update/draw loops, projectile hits, body-touch damage, party dancing) works with zero new plumbing. The behavior is deliberately split from the artwork:

  • Cycle — deterministic: idle 1.6 s → inhale 1.1 s → flame 1.1 s (this.stage, driven by cycleT; opt.offset staggers multiple breathers, opt.cycle retimes the loop).
  • Telegraph — the inhale stage puffs the cheeks up to 2.5× with sparkles and an inhale slide-whistle. A non-reading child learns "big cheeks = fire is coming."
  • Hitbox — flameBox() returns a ground-hugging rect (44 px tall, opt.range long, facing dir); it only exists during the fire stage. Contact: one heart + a gentle shove along the flame, normal invulnerability window. Never a surprise: the box matches the drawn flame.
  • Counterplay — jump over it (the intent), freeze it with ice (pauses the cycle), befriend it with rainbow (retires it), or hit it with fire for a harmless comedy burp.

Cutscenes & endings

game.cut = {name, t} is handled in updateCut (kinds: bossintro, magmaintro, rumble, chestfall, eruption, coronation); player input is frozen during a cutscene. Endings run through game.endPhase phases into 'party' — a big celebratory overlay (drawPartyOverlay) with per-level headline text; pressing Space after 5 s advances the bonus-level chain.

Audio

All procedural WebAudio. One AudioSys.sfx(name) switch for effects; music is a step sequencer reading per-theme note tables in SONGS (every world has its own tune). Audio unlocks on the first user input, as browsers require.

The ten worlds, level by level

Worlds 1–5 are the base game, advanced by star gates; 6–9 are bonus worlds unlocked by beating the previous world's boss or finale. Every level ends in a celebration. "New here" lists mechanics that did not exist in any earlier level; "Cameos" lists returning elements from earlier worlds.

1 · Block Meadow (theme meadow)

Biome
Sunny grass meadow: smiling sun with rotating rays, rolling hills, flowers, round trees, drifting clouds. World 4200 px wide, flat ground at y=620.
Objective
Tutorial run to the star gate. Floating keycap hints teach ◀▶ movement, ▲ jump, and Space to throw.
Enemies
3 walking spiders (purple, googly-eyed, patrol a fixed range).
New here
Everything foundational: running/jumping, candy collecting, hearts, checkpoints, block piles, platforms, the 🔥 fire block and throwing, the star gate.
Pickups
Fire ×2, heart ×1, candy rows and arcs.
Cameos
None — this is the origin. Its walk spider, candy trails, checkpoints, and star gate recur in every later world.

2 · Underwater World (theme water)

Biome
Deep blue sea: light rays, swaying seaweed, coral, background fish, rising bubbles. 4200 × 1200 world (taller than the screen), seabed at y=1130, sandy ruins columns.
Objective
Swim to the star gate on the seabed.
Enemies
5 swimming spiders patrolling open water.
New here
4-direction swimming (lv.water: ▲▼ ascend/descend, gravity off), the ❄️ ice block, and a physics gag: frozen swim-spiders float upward like ice cubes.
Pickups
Ice ×2, heart ×1, candy.
Cameos
Checkpoints, candy trails, star gate. The swim movement introduced here returns as zero-gravity flight in Space Maze (level 9).

3 · Cloud World (theme cloud)

Biome
Sky kingdom: fluffy sleepy-faced cloud platforms, background rainbow arcs, flapping birds. 4600 px wide with no ground — only floating platforms.
Objective
Hop the cloud islands and one-way platforms, activate two rainbow bridges to span the gaps, reach the star gate.
Enemies
2 jumping spiders (new) and 2 walking spiders.
New here
🌈 rainbow block (the befriending mechanic), one-way pass-through platforms, pink bouncy spring blocks, rainbow bridges, and cloud-catch (lv.fallCatch): falling never hurts — a smiling cloud scoops the player back up.
Pickups
Rainbow ×2, heart ×1, candy.
Cameos
Walk spiders from level 1. The spring block returns in Lava World and (as a pink mushroom) in Unicorn Forest; the one-way platforms return as forest branches.

4 · Mountain World (theme mountain)

Biome
Snowy alpine terraces: parallax peaks, falling snow, pine trees, a rocky cave overhang. 4800 px wide, climbing ground tiers (620 → 572 → 524).
Objective
Climb the terraces, use ⭐ power blocks to smash breakable walls, collect the three Mountain Crystals for the shrine to earn the Golden Key, open the locked door, reach the star gate.
Enemies
5 walking, 1 jumping, and 2 hanging spiders (new: dangle on webs under the high ledge and drop on you). The puzzle cave and door approach are deliberately enemy-free.
New here
The ⭐ power block / super mode (6 s of speed, big jumps, shielding, wall-smashing), breakable cracked walls with worried faces — and the game's first adventure mission: a big googly-eyed locked door (bump it → CLUNK + key thought-bubble) between the smashable wall and the gate. The cave under the overhang holds the crystal Shrine — a chest with three empty sockets showing ghost crystals. The three Mountain Crystals are scattered nearby: ice on a block pile at the cave mouth (easy hops), fire on a high ledge reached by a spring-block launch, power sealed in a pocket behind a cracked wall (its glow sparkles over the top — smash through with the power block). Bring all three back and the ceremony opens the chest into a huge Golden Key; it follows the hero to the door, flies into the lock, and the door swings open forever (a candy waits in the doorway).
Pickups
Power ×2, ice ×2, heart ×1, candy, and the mission's Golden Key.
Cameos
Ice blocks from level 2; the sequence-puzzle icons are the fire/ice/power blocks from levels 1–4; the reward chest is Zombie Cave's treasure chest making an early appearance. The super-mode ram introduced here is later required against King Magma (level 6).

5 · Zombie Cave (theme cave) — first boss

Biome
Dark purple cavern: glowing crystals, cartoon skulls, stalactites, sparkle motes. 5000 px wide. The screen is dark (lv.dark) with light pools around the player, crystals, and pickups; a 22-candy trail lights the way.
Objective
Cross the cave and beat the ZOMBIE boss. Three icon-hinted stages: 🔥 fire ×3 → ❄️ ice freeze (he shatters out and stumbles) → 🌈 rainbow, which transforms him into a friend.
Enemies
3 hanging, 2 walking, 1 jumping spider, plus the Zombie boss (arena seals behind a rock wall; dying respawns you inside the arena).
New here
Darkness + light-source rendering, boss fights (game.bossPlan, staged powers, hint bubbles, respawning boss pickups), cutscenes.
Ending
A treasure chest tumbles from the ceiling (chestfall); opening it reveals the GOLDEN CANDY TREASURE → party → unlocks Lava World.
Pickups
Fire ×2, heart ×1, candy trail; boss-stage blocks respawn in the arena.
Cameos
The boss plan is a deliberate reprise of the first three worlds' powers in order: fire (1), ice (2), rainbow (3). Hang spiders from level 4.

6 · Lava World (theme lava) — bonus, second boss

Biome
Volcanic badlands: parallax volcano silhouettes with glowing mouths, rising embers, and the huge sleepy-faced Candy Volcano looming behind the boss arena. 5000 px wide, four glowing lava pools splitting the ground.
Objective
Cross the lava gaps and beat KING MAGMA. His stages invert expectations: 🔥 fire only feeds him — you need ❄️ ice ×3 → a ⭐ super-mode power ram → 🌈 rainbow to befriend him.
Enemies
9 spiders (walk/jump) placed in tight clusters on purpose, plus King Magma (who lobs LavaBlob projectiles).
New here
Ignition chains: in this world fire doesn't pop spiders — it sets them burning; they panic-run, explode, and ignite neighbors for firework chain reactions. Lava pools: falling in bounces you out at the cost of one heart (no deaths).
Ending
The befriended Magma triggers the volcano: rumble → CANDY VOLCANO eruption raining candy → party → unlocks Monster Truck Rally.
Pickups
Fire ×2, ice ×1, heart ×2, candy; boss-stage blocks in the arena.
Cameos
The pink spring block from Cloud World; block piles from Block Meadow; the boss plan reprises ice (2), super mode (4), and rainbow (3). Lava pools go on to reappear as hazards in the Truck Rally.

7 · Monster Truck Rally (theme dirt) — bonus

Biome
Desert rally course: smiling desert sun, flat-top mesas, drifting dust, pennant flags along the track, and a grandstand full of cheering fans at the finish. The longest world: 7200 px.
Objective
Board the monster truck at the start line and race the course — six jump ramps (including THE giant 210 px-tall ramp), a turbo pad, three lava pools to clear — and cross the finish line at x=6420.
Enemies
4 dirt tornadoes (new: tall wandering dust devils), 3 walking and 1 jumping spider.
New here
The truck vehicle (faster than the wheel, monster tires), ramps with automatic mid-air backflips, and the turbo pad (a burst of flame-trailing speed).
Ending
Finish line → grandstand celebration → CANDY TROPHY ("YOU WIN THE RACE!") → party → unlocks Unicorn Forest.
Pickups
Fire, ice, rainbow, heart ×2, big candy arcs over every ramp.
Cameos
Lava pools from Lava World are the track hazards; all three throwable powers appear together for the first time since the base game; walk/jump spiders patrol the infield.

8 · Unicorn Forest (theme forest) — bonus

Biome
Enchanted deep forest: two parallax layers of giant trees, soft god-rays, glowing mushrooms, butterflies, floating rainbow sparkle motes. 5600 × 1100 world with the ground at y=1000 and a pink castle at the far end (x=5060).
Objective
Mount the unicorn and travel the forest — along the ground past centipedes or up through the leafy branch canopy — to the castle, where the royals crown you.
Enemies
3 centipedes (new: multi-segment chains of 5–6 googly faces; a rainbow shot befriends the entire chain at once), plus a walking and a jumping spider.
New here
The unicorn vehicle: mash ▲ to flap winged flight with glitter trails, and its horn fires rainbow shots without needing a block. Pink booster mushrooms (bouncy) launch you into the canopy.
Ending
The coronation cutscene at the castle: you are crowned, and the crown is permanent — game.royal persists in localStorage and the hero wears the crown in every level and on the title screen forever after. Party → unlocks Space Maze.
Pickups
Rainbow ×3, heart ×2, candy arcs through the treetops.
Cameos
Cloud World's one-way platforms return as leafy branches and its spring blocks as pink mushrooms; walk/jump spiders from the base game; the befriending mechanic (level 3) becomes the level's main verb.

9 · Space Maze (theme space) — bonus finale

Biome
Outer space: twinkling parallax starfield, nebula wisps, a sleepy-faced ringed planet, a little red planet, occasional shooting stars. The world is a 44 × 19 cell maze (130 px cells → 5720 × 2470 px) whose connectivity is verified by BFS in the test harness — no sealed rooms, and a long path to the goal.
Objective
Float through the maze — following a candy breadcrumb trail, with hearts and power blocks hidden in dead ends — and touch the giant grinning golden star.
Enemies
12 alien saucers (new: flying-saucer spiders patrolling horizontal or vertical beats). Fire pops them; rainbow befriends them.
New here
Weightless movement (lv.space), a grid-maze level format (lv.mazeGrid), and a goalStar objective instead of a gate.
Ending
Touching the star → MAZE MASTER! — and in the party, all the aliens become friends. The party exit returns to the title screen, completing the chain.
Pickups
Fire ×3, rainbow ×3, heart ×4, candy breadcrumbs along the main route.
Cameos
The zero-gravity controls are Underwater World's swim system reused (lv.water + lv.space); the golden star is the base game's gate star grown into a destination; befriending returns as the kindest way to clear a corridor.

10 · Dino Jungle (theme jungle) — bonus

Biome
Goofy prehistoric jungle: teal-to-green sky, two parallax canopy layers, swaying hanging vines, drifting mist, giant ferns, tropical flowers with faces, prehistoric mushrooms, dino footprints, a distant smoking volcano with a sleepy face — and past the gate, a Secret Dino Valley with a waterfall, a rainbow, and giant flowers. 5800 px wide, ground at y=620 with an elevated shrine terrace at y=430.
Objective
Cross the jungle (jumping the fire-breathers' flames), discover the Ancient Jungle Gate, find the three lost dinosaur eggs and return them to the Nest Shrine to earn the Dino Key, open the gate, and touch the golden star in the Secret Dino Valley.
Enemies
5 fire-breathing dinos (new — see below) in four escalating encounters: a lone tutorial dino on open ground, one beside platforms, a staggered-timing pair, and one guarding the shrine terrace. Plus 2 vine spiders (hang spiders dangling from the canopy).
New here
The FireBreather: a squat orange dino whose cycle is idle → inhale (cheeks puff huge — the unmissable "fire is coming!" telegraph) → a low horizontal flame stream. The flame hugs the ground so jumping over it is the natural answer; touching it costs one heart with a gentle shove, standard invulnerability applies. Ice freezes him (pausing the fire), rainbow befriends him for good, and fireballs just make him burp. Also new: the Three Lost Dinosaur Eggs — the terrace holds the Dinosaur Nest Shrine (a vine-wrapped chest with three empty nest bowls showing ghost eggs), and the eggs are scattered along the jungle: one on a low leaf platform, one high in the canopy reached by a giant bouncy mushroom, and one bobbing right in the shrine guard's flame path (time the fire cycle — or freeze/befriend the guard). Returning with all three runs the nest ceremony, complete with a one-second gag where an egg cracks and a baby eye peeks out. Friendly dinosaurs everywhere: two long-necks that bend their heads toward the hero and blow hearts, a baby triceratops that wanders, sniffs flowers, and hops excitedly when approached, and a goofy T-Rex in the valley with comically tiny arms who stomps, roars… and then sneezes.
Ending
The Ancient Jungle Gate (mossy stone, dino carvings, flanking statues, huge golden keyhole) grinds and shakes when bumped and thinks of a green dino-head key. Bringing the Dino Key makes the stone slab rise into the lintel under falling leaves — and then the GIANT SPINOSAURUS stomps in, roars (and hiccups), and vine-rocks seal the valley on both sides. Boss plan: ❄️ ice ×3 douses his ground-hugging flame breath (cheeks + sail glow during the inhale telegraph; jump the flame like the little fire-dinos taught you) → 🔥 fire ×3 gives him the hiccups (his own medicine) → 🌈 rainbow befriends him: flower behind the ear, crumbling walls, and confetti breath forever after. The valley's golden star (reachable only once he's a friend) starts the SECRET DINO VALLEY party — the Spinosaurus dances → party exit returns to the title.
Pickups
Rainbow ×2 (befriending a fire-breather is a valid strategy!), ice ×1, heart ×2, candy arcs tracing the jump path over every flame.
Cameos
The mission grammar from Mountain World (locked thing → find item → return) with every piece re-themed via configuration; the hang spider reappears as a vine spider; the sequence-puzzle symbols are the familiar power blocks; the golden goal star from Space Maze ends the level; leaf platforms reuse Unicorn Forest's branch drawing.

Progression & persistence

  • Base game: star gates advance 1 → 2 → 3 → 4 → 5.
  • Unlock chain: beating each boss/finale unlocks the next bonus world — Zombie → 6, King Magma → 7, Rally finish → 8, Coronation → 9, Maze star → 10. Party exits chain 5 → 6 → 7 → 8 → 9 → 10 → title.
  • Title screen: hero picker — Jack-Jack (cap) or Becca (curly blonde hair), stored internally as 'boy'/'girl'; Up/Down or tap a portrait — and a level picker of ten medallions (Left/Right, tap, digit keys 1–9 or 0 for world 10; locked worlds show a padlock). Selection defaults to the furthest unlocked level.

Secret keyboard combos (title screen, parents/developers only)

Physical keyboard only — touch-synthesized presses use justP but never the justK map these combos read, so a child mashing touch buttons cannot trigger them. Presses must be ≤1.2 s apart:

  • ▲ Up ×5 quickly — unlock all ten worlds ("ALL WORLDS OPEN!" + fanfare + confetti)
  • ▼ Down ×5 quickly — clear all saved progress and reset to a brand-new game ("BRAND NEW GAME!")
localStorage keyMeaning
ffbg_unlockedHighest unlocked level, 1–10
ffbg_charChosen hero: 'boy' or 'girl'
ffbg_royal'1' after the level-8 coronation — the hero is drawn with a crown everywhere, permanently

Changing the meaning or format of these keys is a MAJOR version bump — it breaks Jack's saved progress.

Testing & verification

  • node test/harness.js — a headless smoke test that stubs DOM/canvas/audio in a Node vm and plays the entire game through: every level, every boss stage, both endings, all vehicles, touch-tap paths, title pickers, versioning checks, and a BFS solvability proof of the space maze. 183 checks; it must print ALL CHECKS PASSED. Run it 2–3× — a flaky pass usually means a real nondeterminism bug. Every new feature and every bug fix gets a check (regression checks have caught three shipped bugs).
  • tools/screenshot.sh <name> '<js-hook>' — real-render screenshots via Windows Chrome headless (WSL interop). Look at the PNGs: the harness's canvas stub cannot catch visual or layering bugs.
  • node --check js/*.js for quick syntax validation.
  • Deploy: commit + push to main; GitHub Pages rebuilds in ~40–60 s. Verify with curl -s <live-url>/js/<file>.js | grep <new-string> — or check the version stamp on the live title screen.

Collaborating: adding levels & features

Established pattern for a new level (every bonus world so far has followed it):

  1. One new traversal mechanic (swim, flight, truck, weightlessness…) + one new enemy + a themed spectacle ending — never just "more platforms".
  2. Add LEVEL_META[n], a buildLevel branch, theme cases in drawBG/drawSolids/drawDecor, and a music entry in SONGS.
  3. Progression hookup: unlock trigger from the previous world's ending, party-chain exit, title medallion + level icon, and every 1..N clamp in game.js — grep for the previous maximum level number to find each spot.
  4. Harness coverage for the new mechanic, enemy, and ending; then screenshots of every new visual.
  5. Bump GAME_VERSION (MINOR), update CHANGELOG.md and this page, tag, push, verify live.

Design guardrails for anything new: it must be understandable without reading (icons/faces/color), losable without punishment (checkpoint + retry), and it should end in a celebration, not a "game over".

Adding an adventure mission to a world

  1. In that level's buildLevel branch: create a MissionGate where progress should stop, push gate.solid into lv.solids, then set lv.mission = new Mission(id, gate, puzzle, item, rewardSpot). That's the whole hookup — game.js already updates and draws lv.mission.
  2. Reuse the collection objective: scatter MissionTokens (pick a skin or add one — e.g. shells), place a Shrine, and wire them with new CollectionPuzzle(tokens, shrine). Example: find 3 magical shells → underwater shrine opens → pearl appears → bring it to the giant clam is exactly new Mission('pearl', clamGate, new CollectionPuzzle(shellTokens, seaShrine), new MissionItem('pearl')) plus artwork. A completely different challenge type just needs to set puzzle.done and call mission.item.revealAt(x, y).
  3. Give each token a different reach challenge (easy / bouncer height / learned mechanic), never sequence-memory or timers; seal mechanic-gated pockets on their far side so they can't be sneaked into.
  4. Theme the gate/item visuals (a clam wanting a pearl, a sleepy cloud wanting crystals…) but keep the grammar: locked thing shows a picture of what it needs; the earned item follows the player.
  5. Keep the challenge area enemy-free, show the clue continuously, make wrong attempts funny and instantly retryable, and never gate the mission behind damage or timing.
  6. Add harness checks that walk the whole flow (blocked → wrong attempt → solve → carry → die with item → unlock → stays open → level still completable), then screenshot every new visual.

Known recurring bug class

Projectile/target height mismatches. Three shipped bugs were variations of "the shot sails N pixels over the enemy's hitbox on flat ground" (fireball vs. spider, unicorn rainbow vs. centipede, crouch-shot). Whenever adding an enemy or a firing height, add a harness check that actually fires the projectile from ground level at the enemy and asserts the hit.
